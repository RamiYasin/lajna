البوابة الموحدة

المجلد HQ: ضع بداخله ملفات نظامك الإداري الحالي بحيث يكون HQ/index.html.
المجلد apply: يحتوي نظام التقديم عبر Discord.
الصفحة الرئيسية: index.html، وتفتح HQ/index.html أو apply/index.html.

نظام التقديم: افتح apply/script.js وعدّل DISCORD_CHANNEL_URL وضع رابط قناة التقديم الفعلي.
عند تعبئة النموذج، يتم نسخ رسالة Discord بالتنسيق المطلوب وفتح القناة. المتقدم يلصق الرسالة ويرسلها يدوياً.
لا يحتاج النظام إلى Bot أو Webhook. يفضّل تشغيل الموقع عبر HTTPS لتفعيل النسخ التلقائي.

تنبيه: مجلد HQ في هذه الحزمة مجرد مكان لوضع ملفات نظامك الحالي؛ لم تكن ملفات HQ الأصلية ضمن الملفات التي أرسلتها.
