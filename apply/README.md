# نظام التقديم عبر Discord

رابط قناة التقديم مضبوط مسبقاً إلى:
`https://discord.com/channels/1545780494271258655/1574078972034289764`

بعد تعبئة النموذج ينسخ النظام الرسالة ويحاول فتح تطبيق Discord عبر رابط التطبيق `discord://-/channels/...`.
إذا منع المتصفح فتح التطبيق، يظهر رابط يدوي لفتح تطبيق Discord ورابط بديل لفتح القناة عبر الويب.
يلزم تثبيت Discord وتسجيل الدخول وامتلاك صلاحية دخول القناة. الصق الرسالة في القناة وأرسلها بنفسك.
